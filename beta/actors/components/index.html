EntityAITimerFlag1

Bases: EntityAITimerFlag1

[EXPERIMENTAL] Fires an event when this behavior starts, then waits for a duration before stopping, with the 1.26.70 options. When stopping due to that timeout or due to being interrupted by another behavior, fires another event. query.timer_flag_1 will return 1.0 on both the client and server when this behavior is running, and 0.0 otherwise. Needs the experimental flag in anvilconfig.json.

Parameters:

Name Type Description Default
priority int

Lower values run first. Game default 0.

 required
control_flags list[ControlFlags]

The controls this goal takes over.

 required
cooldown_range float | tuple[float, float]

Goal cooldown range in seconds. Can be a range object or a single number.

 required
duration_range float | tuple[float, float]

Goal duration range in seconds. Can be a range object or a single number.

 required
on_end EventTrigger | str

Event(s) to run when the goal ends.

 required
on_start EventTrigger | str

Event(s) to run when the goal starts.

 required
trigger_on_end_when_interrupted bool

Whether the on_end events run when another goal interrupts this goal before its duration elapses. Game default true.

 required

Parameters:

Name Type Description Default
azimuth_angle Molang | str | float

Angle in degrees added to the projectile's y axis rotation. Game default 0.

 required
elevation_angle Molang | str | float

Angle in degrees added to the projectile's x axis rotation. Game default 0.

 required
reflected_projectiles list[str | Entity]

Projectiles that are reflected when they hit the entity.

 required
reflection_scale Molang | str | float

Velocity scale of the reflected projectile. Below 1 slows it, above 1 speeds it up. Game default 1.

 required

Sound event played when a projectile is reflected. Game default reflect.

 required

EntitySphericalLookControl

Bases: JsonComponent

[EXPERIMENTAL] Turns the entity's head toward targets set by look behaviors along the shortest arc in 3D, combining upward or downward rotation (pitch) with side-to-side rotation (yaw) in a single turn. Needs the experimental flag in anvilconfig.json.

Look requests turn at the average of the pitch and yaw speeds supplied by the look behavior, optionally scaled by distance. With no look request, the head keeps its current direction unless its pitch is outside pitch_limits, in which case it returns toward the nearest limit at pitch_recovery_speed.

Parameters:

Name Type Description Default
pitch_recovery_speed float

The speed in degrees per second used to return the head's pitch within pitch_limits when no look request is present, from 0 to 3600. 0 disables pitch recovery. It does not limit turning toward requested targets. Game default 60.

 required
reference_distance float

The distance in blocks, above 0, at or below which the look behavior's average pitch and yaw speed applies unchanged. Beyond it, the turn speed is multiplied by reference_distance divided by the target distance, so doubling the distance halves the speed. The distance is measured from the entity's breathing point to the requested look position, and applies only to position targets. Without it, the turn speed is not scaled by distance.

 required
pitch_limits tuple[float, float]

The (min, max) pitch in degrees, each from -90 (straight up) to 90 (straight down), min not above max. Set both to the same value for a fixed pitch. Written as {"min", "max"}. Game default (-90, 90).
