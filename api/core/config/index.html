Core - Config Module

anvil.lib.config

CONFIG_FILE = Path('anvilconfig.json') module-attribute

The project's config file, in the current folder.

NAMESPACE_PATTERN = re.compile('(?!minecraft$)[a-z][a-z0-9_]{0,7}') module-attribute

A project namespace: 1 to 8 lowercase letters, digits or _, starting with a letter, and not minecraft.

PROJECT_NAME_PATTERN = re.compile('[a-z][a-z0-9_]{0,15}') module-attribute

A project name: 1 to 16 lowercase letters, digits or _, starting with a letter.

AnvilConfig dataclass

The settings of an Anvil project, read from its anvilconfig.json.

It only holds values: building one never prompts, prints, writes a file or uses the network. load_project does that work for the project in the current folder.

CONFIG is the shared instance. It loads the project in the current folder the first time one of its settings is read.

BP_PATH property

The development behavior pack folder.

RP_PATH property

The development resource pack folder.

Configuration options available in the anvil config file.

Defines all the configuration keys that can be set in various sections of the configuration file.

Bases: StrEnum

Package target types for anvil projects.

Defines the types of packages that can be created.

ConfigSection

Bases: StrEnum

The sections of anvilconfig.json.

  • package: what the project is: its namespace, names, descriptions and target.
  • manifest: what the pack manifests carry: the release version and the UUIDs.
  • features: what the project's content uses: Script API, Script UI, PBR, experimental features and the world's random seed.
  • build: how the project is built and exported.
  • anvil: what Anvil records on its own: the last version check and the latest vanilla version it found.

Loads the project in the current folder.
