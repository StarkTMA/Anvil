AnvilFormatter

convert_color(color, target=None) classmethod

Converts a color from any supported format to the target format.

Supported input formats: - Hex string: "#RRGGBB", "#RRGGBBAA", "#RGB", or "#RGBA" (short format) - RGB/RGBA (0-1): tuple of 3 or 4 floats in range [0, 1] - RGB255/RGBA255 (0-255): tuple of 3 or 4 ints in range [0, 255]

Parameters:

Name Type Description Default
color Color

The input color in any supported format.

 required
target Color | None

The target color type (RGB, RGBA, RGB255, RGBA255, HexRGB, or HexRGBA). If None, returns normalized version of input format.

 None

Returns:

Name Type Description
Color Color

The color converted to the target format.

Raises:

Type Description
ValueError

If the color format is invalid or cannot be determined.
TypeError

If the color type is not supported.

Examples:

>>> convert_color("#FF0000", RGB)
(1.0, 0.0, 0.0)
>>> convert_color("#F00", RGB)
(1.0, 0.0, 0.0)
>>> convert_color("#F00")  # No target, normalizes to full hex
"#ff0000"
>>> convert_color((1.0, 0.0, 0.0), HexRGB)
"#ff0000"
>>> convert_color((1.0, 0.0, 0.0), HexRGBA)
"#ff0000ff"
>>> convert_color((255, 0, 0), RGB)
(1.0, 0.0, 0.0)
>>> convert_color((0.5, 0.5, 0.5), RGBA)
(0.5, 0.5, 0.5, 1.0)
>>> convert_color((128, 64, 32))  # No target, normalizes to RGB255
(128.0, 64.0, 32.0)

AnvilValidator

check_script_versions(preview=False, experimental=False) classmethod

Warns about installed Script API npm packages newer than what Anvil supports.

The manifest still pins the module versions Anvil supports, so the game uses those. A newer package only exposes APIs that will not work in game.

Parameters:

Name Type Description Default
preview bool

The project builds for Minecraft Preview.

 False
experimental bool

The project uses experimental features.

 False

is_color_value(value) classmethod

Check if a value is a color value (not a texture file name). Returns True for RGB/RGBA tuples and hex color strings. Returns False for texture file names (plain strings without # prefix).

supported_npm_versions(preview=False, experimental=False) classmethod

The newest version of each Script API npm package that Anvil targets.

@minecraft/server and @minecraft/server-ui follow the behavior pack manifest's module dependencies, which use the beta modules only for preview projects with experimental features. @minecraft/vanilla-data follows the game version.

Parameters:

Name Type Description Default
preview bool

The project builds for Minecraft Preview.

 False
experimental bool

The project uses experimental features.

 False
