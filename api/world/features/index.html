    World - Features Module

    anvil.api.features

    World generation features: what is placed in the world, such as a block, a scatter of other features or a structure. A feature is only placed when a :class:~anvil.api.features.feature_rule.FeatureRule attaches it to biomes, or when another feature, a sapling or /place feature places it.

    Each feature type writes one typed document. Its file class builds it with the same methods as before: the constructor takes the options every feature of that type needs, and methods set the rest. Values are checked when the file is exported.

    Example 
    flower = SingleBlockFeature("blue_flower").place_block("minecraft:cornflower")
flower.may_replace(["minecraft:air"])

patch = ScatterFeature("blue_flower_patch", flower)
patch.distribution(8, None, CoordinateRange("uniform", (-4, 4)), 0, CoordinateRange("uniform", (-4, 4)))

    Documentation reference

    anvil.api.features.feature

    The base of every feature type, and the distribution shared by scatter features and feature rules.

    Each feature type has its own module with three classes: _XFeature is the body of the feature, _XFeatureFile is the document written to the file (format_version and the body under its minecraft: key), and XFeature is the file class you create and build.
